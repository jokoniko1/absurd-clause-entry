# Absurd Clause Entry

A single deadpan clause, written as if buried deep in a terms-of-service agreement: it quietly grants the Company a perpetual licence to borrow the reader's dreams on Tuesdays for quality assurance purposes. The program writes exactly that one sentence to `/output/entry.txt`.
